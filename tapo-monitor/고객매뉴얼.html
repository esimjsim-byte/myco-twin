1. 시스템 개요

Tapo Monitor는 재배실의 온도·습도를 실시간으로 모니터링하고, 설정된 임계값을 초과하면 환풍기·가습기·FCU를 자동으로 ON/OFF 하는 시스템입니다.

주요 기능

기능설명
실시간 모니터링9개 구역의 온도·습도를 웹 대시보드에서 실시간 확인
자동 제어 (Tapo)TP-Link Tapo P100/P110 스마트플러그를 LAN으로 ON/OFF
자동 제어 (PLC)Modbus TCP로 PLC 코일 제어 (FCU, 가습기, 환풍기)
구역별 임계값구역마다 다른 온도·습도 기준 설정 가능
데이터 저장SQLite DB에 측정 이력 자동 저장 (7일 보관)

시스템 구성도

[온습도 센서] ──── [H100 허브] ──── [Tapo Monitor PC] │ ┌──────────────────────┼──────────────────────┐ │ │ │ [Tapo 스마트플러그] [PLC Modbus TCP] [웹 대시보드] 환풍기 / 가습기 FCU / 가습기 / 환풍기 http://localhost:3000

자동 제어 동작 규칙

조건FCU (코일1)가습기 (코일2 / plugIp2)환풍기 (코일3 / plugIp1)
온도 > TEMP_MAXON—ON
온도 < TEMP_MINON—OFF
습도 > HUMID_MAX—OFFON
습도 < HUMID_MIN—ON—
정상 범위OFF현상 유지OFF

2. 설치 전 준비사항

아래 두 프로그램이 PC에 미리 설치되어 있어야 합니다.

2-1. Node.js 설치

웹 브라우저에서 https://nodejs.org 에 접속합니다.
LTS (장기 지원 버전) 다운로드 버튼을 클릭합니다.
다운로드된 설치 파일을 실행하고 Next를 눌러 기본 설정으로 설치합니다.
설치 완료 후 명령 프롬프트(cmd)를 열어 아래를 입력합니다:
node --version npm --version

각각 버전 번호가 출력되면 정상입니다. (예: v22.x.x, 10.x.x)

2-2. Git 설치

웹 브라우저에서 https://git-scm.com/download/win 에 접속합니다.
Click here to download 링크를 클릭합니다.
다운로드된 설치 파일을 실행하고 기본 설정으로 설치합니다.
설치 완료 후 명령 프롬프트에서 아래를 입력합니다:
git --version

git version 2.x.x 형태로 출력되면 정상입니다.

참고: 두 프로그램 모두 설치 후 명령 프롬프트를 새로 열어야 PATH가 적용됩니다. 기존에 열어두었던 cmd 창에서는 인식되지 않을 수 있습니다.

3. install.bat 실행 방법

전달받은 install.bat 파일을 바탕화면(또는 원하는 폴더)에 놓습니다.
install.bat 파일을 더블클릭합니다.
검은 창(명령 프롬프트)이 열리면서 자동으로 아래 작업이 수행됩니다:
  • Git / Node.js 설치 여부 확인
  • GitHub에서 프로젝트 소스 코드 다운로드
  • 필요한 패키지(npm) 자동 설치
  • .env 환경설정 파일 자동 생성
  • TypeScript 빌드
"설치가 완료되었습니다!" 메시지가 나오면 아무 키나 눌러 종료합니다.
설치 결과 폴더:
바탕화면에서 실행한 경우 → 바탕화면\myco-twin\tapo-monitor\
이미 tapo-monitor 폴더 안에서 실행한 경우 → 해당 폴더에 바로 설치 (중복 생성 안 됨)
"git clone 실패" 오류가 뜨는 경우:
① 인터넷 연결을 확인하세요.
② GitHub 저장소가 비공개(private)라면 GitHub 계정 인증이 필요합니다. 담당자에게 문의하세요.

4. .env 파일 설정 방법

install.bat이 자동 생성한 .env 파일을 메모장(또는 VS Code)으로 열어 실제 값을 입력합니다.

파일 위치

myco-twin\tapo-monitor\.env
주의: .env 파일은 탐색기에서 보이지 않을 수 있습니다.
탐색기 상단 → 보기 → "숨김 항목" 체크를 켜거나,
명령 프롬프트에서 notepad .env 를 입력해 직접 열 수 있습니다.

4-1. 필수 설정 (계정 / IP)

항목설명예시
TAPO_EMAILTapo 앱 로그인 이메일hw.kwon@sinsungo.co.kr
TAPO_PASSWORDTapo 앱 로그인 비밀번호(실제 비밀번호 입력)
HUB_IPH100 허브의 로컬 IP192.168.0.100
PLUG_IP_1환풍기 스마트플러그 IP192.168.0.101
PLUG_IP_2가습기 스마트플러그 IP192.168.0.102
IP 확인 방법:
① Tapo 앱 → 각 기기 선택 → 기기 정보에서 IP 확인
② 또는 공유기 관리자 페이지 → DHCP 클라이언트 목록에서 "Tapo" 이름 검색

4-2. PLC 설정

항목설명기본값
PLC_IPPLC의 로컬 IP192.168.0.50
PLC_PORTModbus TCP 포트502
PLC_COIL_FCUFCU 코일 번호1
PLC_COIL_HUMIDIFIER가습기 코일 번호2
PLC_COIL_VENTILATION환풍기 코일 번호3

4-3. 구역별 이름 설정

ZONE_COUNT=9 SENSOR_1_NAME=1구역 SENSOR_2_NAME=2구역 SENSOR_3_NAME=3구역 ... SENSOR_9_NAME=9구역

구역 이름은 자유롭게 바꿀 수 있습니다. 대시보드 카드에 이 이름이 표시됩니다.

4-4. 구역별 임계값 설정 (선택)

특정 구역에만 다른 임계값을 적용하려면 아래처럼 추가합니다:

# 2구역만 더 엄격한 기준 적용 SENSOR_2_TEMP_MAX=26 SENSOR_2_TEMP_MIN=20 SENSOR_2_HUMID_MAX=90 SENSOR_2_HUMID_MIN=60

설정하지 않은 구역은 전역 기본값 (TEMP_MAX, TEMP_MIN, HUMID_MAX, HUMID_MIN)을 자동으로 사용합니다.

5. 프로그램 실행 (npm start)

명령 프롬프트(cmd)를 엽니다.
tapo-monitor 폴더로 이동합니다:
cd %USERPROFILE%\Desktop\myco-twin\tapo-monitor
프로그램을 빌드하고 실행합니다:
npm run build npm start
아래와 비슷한 메시지가 나오면 정상입니다:
Dashboard: http://localhost:3000 tapo-monitor started (poll=60000ms)
프로그램을 종료하려면 명령 프롬프트에서 Ctrl + C 를 누릅니다.

6. 대시보드 접속 방법

프로그램이 실행 중인 상태에서 웹 브라우저(Chrome 권장)를 엽니다.
주소창에 아래를 입력합니다:
http://localhost:3000

대시보드 화면 구성

영역설명
상단 헤더전체 경보 요약 ("정상 9/9" 또는 "임계값 초과: N개 구역"), 실시간 연결 상태
9개 카드각 구역의 현재 온도·습도. 임계값 초과 시 빨간 테두리 + "경보" 표시
하단 그래프선택한 구역의 시간별 온도·습도 변화 (1시간/6시간/24시간 선택 가능)
실시간 갱신: 대시보드는 SSE(Server-Sent Events)로 자동 업데이트됩니다.
우측 상단 "● live"가 초록색이면 정상입니다. "재연결 중"이면 프로그램이 꺼져 있는지 확인하세요.

7. 임계값 변경 방법

전역 임계값 (전체 구역 기본값)

.env 파일에서 아래 항목을 수정합니다:

TEMP_MAX=28 # 온도 상한 (°C) - 초과 시 환풍기 ON TEMP_MIN=18 # 온도 하한 (°C) - 미달 시 FCU ON HUMID_MAX=95 # 습도 상한 (%) - 초과 시 가습기 OFF, 환풍기 ON HUMID_MIN=50 # 습도 하한 (%) - 미달 시 가습기 ON

특정 구역만 다르게 설정

# 예: 3구역만 온도 범위를 좁게 설정 SENSOR_3_TEMP_MAX=25 SENSOR_3_TEMP_MIN=20
임계값을 변경한 후에는 프로그램을 재시작해야 적용됩니다.
① 실행 중인 cmd 창에서 Ctrl + C 로 종료
② npm start 로 다시 시작

8. Windows 자동 실행 설정

Windows에 로그인할 때마다 Tapo Monitor가 자동으로 시작되도록 설정할 수 있습니다.

자동 시작 등록

tapo-monitor 폴더 안의 setup-autostart.bat 을 더블클릭합니다.
"등록이 완료되었습니다" 메시지가 나오면 성공입니다.
다음 로그온부터 자동으로 실행됩니다 (창 없이 백그라운드 동작).

자동 시작 해제

tapo-monitor 폴더 안의 uninstall-autostart.bat 을 더블클릭합니다.
예약된 작업이 삭제되고 자동 실행이 중단됩니다.

즉시 실행 / 상태 확인 (명령어)

# 재부팅 없이 즉시 실행 schtasks /Run /TN "TapoMonitor" # 실행 상태 확인 schtasks /Query /TN "TapoMonitor" /V /FO LIST

9. 문제 해결

증상원인 및 해결
"Missing required env var" 오류 .env 파일에 필수 항목이 빠져 있습니다. 4장을 참고하여 모든 항목을 입력하세요.
handshake failed / 403 오류 ① .env 에 입력한 Tapo 이메일/비밀번호가 맞는지 확인하세요.
② 플러그 IP가 올바른지 Tapo 앱에서 다시 확인하세요.
③ PC와 Tapo 장치가 같은 Wi-Fi 네트워크인지 확인하세요.
EADDRINUSE 포트 3000 사용 중 다른 프로그램이 포트 3000을 사용 중입니다.
.env 에서 DASHBOARD_PORT=3001 로 변경 후 재시작하세요.
대시보드 "재연결 중" 표시 프로그램(npm start)이 꺼져 있습니다.
cmd에서 npm start 를 실행하거나 schtasks /Run /TN "TapoMonitor" 으로 시작하세요.
PLC 코일 동작 안 함 ① PLC_IP 가 정확한지 확인하세요.
② PLC의 Modbus TCP 기능이 활성화되어 있는지 확인하세요.
③ 코일 번호가 PLC 프로그램과 일치하는지 확인하세요 (0-인덱스 차이 주의).
npm 명령어를 찾을 수 없음 Node.js가 설치되지 않았거나 PATH에 등록되지 않았습니다.
Node.js를 재설치하거나 명령 프롬프트를 새로 여세요.
install.bat 실행 시 "git clone 실패" ① 인터넷 연결 확인
② 저장소가 private이면 GitHub 인증(로그인 팝업) 필요
③ 방화벽/프록시가 GitHub를 차단하는지 IT 담당자에게 확인
